# 文件式资料库与知识包

本模块提供资料登记、分析、复核、版本化修订和检索，不附带内部小说库、旧卡或派生观察。新安装的资料库为空。文件结构见 [FILE-LIBRARY.md](FILE-LIBRARY.md)，当前检索参数见 [RETRIEVAL.md](RETRIEVAL.md)。

## 资料服务

`createLibraryService({rootDir, model, reviewAnalysis?, reviewCandidates?})` 从 `library.mjs` 导出。产品注入模型与专属持久目录；一个进程持有一个资料库目录，避免多个服务同时写入。

上传保留原始字节与固定版本的可读原文。分析须通过引文、位置与协议校验，再单独复核。记录包含来源、文本版本、分析版本及实际复核身份；复核状态不能替代内容准确性或文学效果判断。重复上传关联规范来源，避免把同一原文重复计算为不同资料。

任务中断后保留完成阶段，重启不会自动重复模型调用；恢复、取消和迟到响应分别处理。目录及索引通过临时文件和原子替换保存，当前不提供远程多实例或断电级事务保证。

## 分析修订

外部修订先登记候选，经过显式独立复核后才发布新分析和索引。旧分析仍可回读，旧引用不能静默改绑新版。字段、版本与复核合同见 [submitted-analysis-contract.md](submitted-analysis-contract.md)。

## 检索与供给

原文窗口与分析单元进入有限候选集合，相关性判断、完整材料分配和创作实际采用分别记录。已复核分析携带复核记录和来源定位；未复核分析不能当作已批准材料供给。完整窗口超出预算时跳过，不以裁剪引文凑满材料。

已判定可用的候选在既有预算内优先保留不同来源及完整材料的机会，防止大分析包占满单元预算。此分配不重新判断相关性，也不强制创作采用。是否改善作品仍需全文对照验证。

## 固定知识包

`prepareKnowledge(request, {retrievalResult})` 保留用户选定材料、风格设置及可选的固定检索结果，核对内容哈希与来源。公开版的内置观察为空，不会读取内部材料。没有材料时可继续通用创作；恢复使用已保存的输入包，不隐式重查资料。

测试模型使用明确的合成替身。从产品目录执行 `npm run test:runtime` 可复验公开包中的资料筛选与工作流测试。测试通过不证明材料语义准确或具有普遍创作增益。
