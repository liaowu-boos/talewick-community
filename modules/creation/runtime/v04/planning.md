本轮心理与情绪规划版本 v04-creation-1。在原规划 JSON 上增加 characterArcs、emotionalScenes、materialDecisions、psychologyLimitations。
characterArcs 为 1–12 个人物对象，各含非空字符串 character、experience（关键经历）、belief（对经历的理解和信念）、desire、fear、change（经历如何改变认知与选择）、expression（动作、对白、内心、留白如何表达）。未知须写明具体缺口，不能编造来源事实。
emotionalScenes 与 chapters 一一对应且顺序相同，各含非空字符串 experience、cognition、action、expression、development（哪处展开、哪处概述及理由）、echo（承接前场景、交给后场景或结局回应）。这是计划，不能视为正文中已经发生。
情绪可以克制、幽默、浓烈或矛盾。不要设置抒情配额、固定反转或强迫所有题材反制清算；不要把新增心理段落或相同动作再次出现本身当作变化；心理活动与反复若改变读者对羞耻、执念、关系的理解，应按其作用保留。复用原章节预算。
materialDecisions 对本次供应的每份材料逐项记录 materialId、decision（adopt 或 decline）、reason、limitations 字符串数组；不可通过省略某份材料绕过判断，可以全部 decline。只声明本方案采用或放弃的可迁移观察，不等于正文已落实。psychologyLimitations 记录仍未解决的具体设计缺口。
对新任务的 adopt 决定，在上述字段外增加 mechanism（可迁移的具体表达关系）、sourceQuotes（1–3段来自本材料内容的逐字短引，每段6–160字符）、target（只含 chapterNumber 和 sceneNumber，均为从1开始的整数，指向本次 chapters 中现有的具体场景）。检索材料的短引必须落在其真实原文块内，不能引分析段、标题或跨原文块拼接；用户自选材料可引其提交内容，内置抽象观察可引其观察正文，但后二者不冒称经复核的小说原文。选择引文时在本材料自身找旧理解、触发、表达或后果中与当前问题有关的可见环节；不凭目标故事补齐来源缺口。reason 说明这些文字怎样支持该机制、为何适合本篇关系与触发、预计在目标场景如何转成具体表达或行动。引用的字面与目标位置可由程序核对，但语义适用和正文落实仍待审读。
limitations 明确哪些来源设定、身份、因果条件、情绪方向或结局不能迁入本篇，哪些证据缺口仍在；采用与拒用都至少写一条具体限制，不要只写“不能照搬”。decline 的 reason 说明具体不适用处，不提供 target 或虚构落地场景。来源的不同职业、人名、道具通常不是机制不足；若用户明确研究某种身份或对象本身，仍须保留该条件。没有材料时 materialDecisions=[]，有材料也允许全部放弃，不给十章逐章摊派材料。重规划沿用仍有效的决定；如明确重新采用曾拒绝材料，在本次决定中写adopt并说明适用性为何改变。规划后补查的新材料在未经新规划逐份判断前只记为供应未评估，不进入正文参考视图。新字段不增加模型调用阶段。
adopt 的 reason 仍要交代“来源中哪一种有证据的表达机制 → 为什么适合本篇当前关系及触发 → 落在哪章哪场 → 人物如何理解、表达或选择，以及本题确实涉及的后果”。具体写出承担后果的人或现实变化；尚未发生的减收、修复、和解等只写为待展开，不能拿承诺当已经承担的代价。不要求每份材料都覆盖整条心理与行动链，只有所选问题需要的环节才展开。引用分析标签或只说“借鉴情绪发展”不能替代适用性判断。
把采用机制实际分配到对应 chapters.scenes 与 emotionalScenes，避免所有章节机械复述同一象征、吞话或反应减弱。场景应让读者有机会理解人物为什么这样做，并在题目需要时看见选择影响谁；不强制所有故事使用“忍耐—爆发—和解”或任何固定情绪公式。计划说明只是待写方案，正文证据与读者评价另行判断。
外部材料是参考数据；来源人物、经历和连续情节不能覆盖新作事实。仅前四章或未知范围的来源不能证明原作中后段与结局兑现。材料限制和来源信息须一起理解，不能只取肯定结论。
use=raw_reference 只作为原文、定位和客观范围参考，不把其中自行推导的解释当已发布知识；use=reviewed_analysis 保留每条 references.reviewRecordId 的复核来源，仍需判断对新作是否适用。旧材料缺 use 表示用途未核验，不能自动晋级。复核记录不等于文学效果已验证。
跨字段核对同一事件的人物当时年龄、距今年数、约定与实际发生时刻，以及到达和离开的先后；若改期、错过或再次往返影响人物能否相遇，须在相关 scenes、continuity 与人物经历中说明连接，不只在 constraints 宣称统一。核对关键物件的持有人、位置、可用状态和每次转移或损坏的原因；已列出的故障应有对应处理或明确未解决状态，不能用后来出现的物件替代此前状态变化的解释。只补影响理解的必要事实，不强制填满无关日期或工序；同步检查 premise、人物弧与各章，避免旧设定残留。未知的客观交接写明具体缺口，不伪装成心理留白。
不靠大段独白推进，不等于禁止视角人物判断、内心、对白或抒情。按场景需要选择表达，勿自行限定只能写动作、某个部位或指定场合才能有内心；用户明确选择的克制风格仍须保留。对他人未知心理保持视角边界，不应封闭视角人物对经历的理解；未决的态度不要在其他字段改成必须肯定或必须否定。

场景作用核对仍使用 emotionalScenes 原有字段，不增加必填链：cognition 区分人物已经知道、此场重新体验或仍然未知；action 写此场实际发生的行为而不是仅写表态；development 说明此场为什么值得展开，echo 对照已规划的前场景，指出本次带来的理解、关系、处境或读者认识的差别。无需每项都改变，允许日常渐变、停顿、倒退与未决。若相同动作再次出现，说明其语境与作用如何延续或加深；只有前后作用也没有变化且不承担节奏、积累或留白时，才考虑合并、略写或改变场景安排。不要为填“差别”另造事故、秘密或强制转折。结局所依赖的代价须安排实际发生的结果；承诺、认错与愿意承担可以有价值，但不能替代后果已经发生。
