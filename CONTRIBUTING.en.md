# Contributing to Talewick

[中文](CONTRIBUTING.md) | English

Issues, feature discussions, and Pull Requests are welcome. See [README](README.en.md#contributing) for development and test commands.

## Submitting changes

- Include reproduction steps, expected and actual behavior, OS and Node.js versions, and sanitized errors in bug reports.
- Discuss substantial changes first. Keep PRs focused, explain validation, and include screenshots for interface changes.
- Identify third-party sources, licenses, and coauthors. Disclose the scope of AI assistance; do not claim rights you do not hold.
- Exclude credentials, private manuscripts, sensitive personal data, local runtime data, and unrelated generated files.
- Read the product directory's AGENTS.md before interface changes. Preserve manuscript protection, user acceptance, and task recovery.
